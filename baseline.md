## Бейзлайн
В качестве бейзлайна была взята модель [X-CLIP](https://huggingface.co/microsoft/xclip-base-patch32) от Microsoft. Модель обучена для решения задачи классического video-text retrieval.<br>
## Минусы модели для нашей задачи:
1. Тестовый энкодер обучен для английского. Для подсчета бейзлайна потребовался перевод всех реплик.
2. Модель работает лишь с 8 кадрами из видео. Если для классического video-text retrieval этого достаточно, то вряд ли это сработает для жестового языка, так как для восприятия жестовой фразы требуется захватывать больше движения.
3. Модель не предназначалась для жестовых языков.
## Результаты и метрики
Мы рассмотрели три метрики:
 * Hit@1 - попадание целевого соответствия в топ-1
 * Hit@100 - попадание целевого соответствия в топ-100
 * MRR - среднеобратный ранг<br>

|         | X-CLIP  |
| ------- | ------  |
| Hit@1   | 0.00036 |
| Hit@100 | 0.03801 |
| MRR     | 0.00321 |
